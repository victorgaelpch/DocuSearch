# Data local

Los documentos originales, los índices, los textos extraídos y las bases locales no se versionan. Desde DOC-02 el backend usa `data/originals/<colección>/`, `data/metadata.db` y `data/indexes/` (raíz configurable con `DOCUSEARCH_DATA_DIR`).

No subir documentos privados ni datos sensibles al repositorio.
